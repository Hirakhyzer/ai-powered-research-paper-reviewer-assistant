# Security Policy

## Scope

This repository is a research prototype for AI-assisted peer-review support using synthetic manuscripts by default.

Security issues may include:

- Unsafe handling of confidential manuscripts.
- Path traversal or unsafe file-output behavior.
- Dependency vulnerabilities.
- Accidental exposure of private review content.
- Misleading claims that encourage automated peer-review decisions.

## Confidential manuscript warning

Do not process confidential, unpublished, or copyrighted manuscripts unless you have explicit authorization and appropriate safeguards. The default project workflow uses synthetic fictional papers to avoid this risk.

## Reporting a vulnerability

Please open a GitHub issue for non-sensitive concerns. For sensitive security concerns, avoid posting exploit details publicly. Provide:

- A clear description of the issue.
- Steps to reproduce.
- Affected files or commands.
- Possible impact.
- Suggested mitigation if known.

## Responsible-use boundary

This project is not an automated editorial decision system, plagiarism detector, misconduct detector, or ranking tool. Security and governance concerns include misuse that could harm authors, reviewers, or institutions.

## Maintainer response

The maintainer will review reports, clarify scope, and update code or documentation where appropriate.
