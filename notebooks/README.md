# Notebook guidance

Use the Python modules in `src/paperreview` to build an exploratory notebook after running the synthetic pipeline.

Suggested cells:

1. Load `outputs/results/synthetic_papers.csv`.
2. Load `synthetic_methodology_audit.csv`, `synthetic_citation_comparison.csv`, and `synthetic_paper_quality_scores.csv`.
3. Inspect the highest methodology-risk papers.
4. Compare quality-support scores by field.
5. Review the generated reviewer checklist.

Do not upload confidential manuscripts or reviewer comments into notebooks unless proper authorization and governance are in place.
