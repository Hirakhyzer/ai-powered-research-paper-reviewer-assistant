# Governance and Boundaries

This repository is an independent research prototype for AI-assisted peer-review support. It uses synthetic papers by default and is intended for research, teaching, and software prototyping.

## 1. Intended uses

Acceptable uses include:

- Building reproducible reviewer-support workflows.
- Teaching peer-review structure and research integrity.
- Studying human-AI collaboration in scholarly evaluation.
- Prototyping methodology and reproducibility checklists.
- Comparing transparent review-support rules.
- Generating synthetic datasets for safe experimentation.

## 2. Non-intended uses

The project is not intended for:

- Automatic paper acceptance or rejection.
- Academic misconduct determinations.
- Plagiarism accusation workflows.
- Editorial decision automation.
- Grant, hiring, grading, promotion, or tenure decisions.
- Confidential manuscript processing without explicit authorization and safeguards.
- Ranking researchers, departments, journals, universities, or countries.

## 3. Data boundary

The default workflow uses synthetic fictional papers. This is important because real peer-review manuscripts may be confidential, unpublished, copyright-protected, or subject to editorial policy.

Real manuscript use would require:

- Permission to process the manuscript.
- Confidentiality controls.
- Secure data storage and deletion plan.
- Conflict-of-interest handling.
- Clear reviewer and editorial policy alignment.
- Human expert verification.

## 4. Human oversight principle

All outputs should be interpreted as **review-support signals**. The system can help a human reviewer inspect a paper more systematically, but it cannot determine novelty, correctness, ethical compliance, or publication merit by itself.

## 5. Transparency requirements

If the system is used in a study or demonstration, disclose:

- That the output is generated by a prototype.
- Whether papers are synthetic or real-permissioned.
- The rubric and rules used.
- The limitation that outputs are not peer-review decisions.
- The human verification process.

## 6. Risk controls

Recommended controls:

- Keep synthetic data as the default.
- Do not upload confidential manuscripts into unmanaged environments.
- Do not make automated final decisions.
- Store audit logs only when appropriate.
- Avoid publishing review-support outputs that expose confidential manuscript content.
- Record limitations honestly.

## 7. Academic integrity statement

This repository should support better scholarly judgment. It should not fabricate citations, invent evidence, create false review authority, or reduce peer review to a single automated score.
