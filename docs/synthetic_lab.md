# Synthetic lab

The default experiment creates a fictional research-review dataset. Generated paper text, citations, weaknesses, and scores are not real scholarly records.

## Synthetic artifacts

- Research paper table
- Citation library
- Paper-citation links
- Paper summaries
- Methodology audit
- Citation coverage comparison
- Reproducibility checklist
- Reviewer checklist
- Paper-quality support scores
- Markdown report
- Figures
- Hash-chained audit log

## Why synthetic first?

Synthetic data allows the full reviewer-support workflow to run without private manuscripts, confidential reviews, publisher PDFs, or author-identifying information.
