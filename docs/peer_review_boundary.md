# Peer-review boundary

This repository is independent reviewer-support infrastructure. It uses synthetic papers by default and should not process confidential manuscripts unless proper authorization, confidentiality controls, and data governance are in place.

The system must not be used as the sole basis for:

- accepting or rejecting papers;
- ranking authors or researchers;
- plagiarism accusations;
- academic misconduct determinations;
- grant, hiring, tenure, or promotion decisions;
- bypassing expert peer review.

All outputs are prompts for careful human review. Real-world use requires expert reviewers, conflict-of-interest handling, confidentiality policy, editorial process, and field-specific judgment.
